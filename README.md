

# StockPulse – Interactive Stock Market Dashboard

StockPulse is an interactive web dashboard I developed to make stock market analysis simple and intuitive. I built this project to provide a clean visual interface for tracking major stocks, checking key metrics, and comparing performance side-by-side.

## Key Features
Market Overview: Prices and trends for top companies like Apple or NVIDIA (unfortunately I didn't managed to get the live data transmitted).
Interactive Charts: Visualize historical stock performance across custom timeframes (1D, 1W, 1M, 1Y).
Stock Comparison Tool: Compare two stocks side-by-side to analyze percentage-based trends.
Financial Metrics: Quick insights into Market Cap, P/E Ratio, and 52-Week Highs/Lows.
Beginner's Glossary: Built-in glossary explaining essential financial terms.
